# 設備計算ラボ（General-Calculation）

建築設備設計（空調・換気、給排水衛生、電気設備、消防・防災）のための汎用計算サイトです。
ブラウザだけで動き、インストールや会員登録は要りません。

## 主な機能

- 計算ツール（現在50件）
  - 空調・換気（12件）：HV-01 必要換気量、HV-02 室の冷暖房負荷、HV-03 外気負荷・すきま風負荷、HV-04 湿り空気の状態、HV-05 熱貫流率と表面結露の判定、HV-06 発熱除去の換気量、HV-07 シックハウス対策の換気量、HV-08 ダクトの寸法（等摩擦法）、HV-09 送風機の静圧・軸動力、HV-10 冷温水量・冷却水量、HV-11 冷温水ポンプの全揚程、HV-13 空調機の送風量と顕熱比
  - 給排水衛生（14件）：PL-01 受水槽・高置水槽容量、PL-02 給水負荷単位と給水管径、PL-03 給水管の摩擦損失、PL-04 給水ポンプの全揚程、PL-05 給湯量・加熱能力・貯湯容量、PL-06 排水負荷単位と排水管径、PL-09 屋根雨水の排水量と管径、PL-10 排水槽の容量・排水ポンプ、PL-11 浄化槽の処理対象人員、PL-12 事業場の便所の必要個数、PL-14 給水管の許容摩擦抵抗と管径、PL-15 瞬間湯沸器の号数、PL-16 給湯循環ポンプ、PL-17 災害時の必要水量と非常用排水槽
  - 電気設備（12件）：EL-01 電圧降下、EL-02 電力⇔電流換算、EL-03 絶縁電線の許容電流、EL-04 低圧幹線の許容電流と過電流遮断器、EL-05 低圧分岐回路の遮断器・電線・コンセント、EL-06 三相短絡電流、EL-07 変圧器容量（需要率・不等率）、EL-09 照度計算（光束法）、EL-10 非常用照明の照度（逐点法）、EL-11 接地抵抗の基準値と判定、EL-12 低圧電路の絶縁抵抗の判定、EL-16 電線管の太さ（占積率）
  - 消防・防災（7件）：FP-01 屋内消火栓の水源・ポンプ、FP-02 スプリンクラーの水源・ポンプ、FP-03 消火器の必要能力単位、FP-04 感知器の必要個数、FP-05 誘導灯の有効範囲、FP-06 排煙機の必要排煙量、FP-07 自然排煙口の必要開口面積
  - 共通・単位換算（5件）：CM-01 単位換算（圧力・流量・熱量・温度）、CM-02 管内流速・必要内径、CM-03 ポンプ・送風機の軸動力、CM-04 顕熱の熱量・流量換算、CM-06 設備機器の耐震（アンカーボルト）
- 計算根拠の表示：計算式と代入値を並べて表示
- 明細表：器具や区間などを行で並べて入力し、列の計算と合計を求める（Excel でも関数で集計）
- 計算式の解説・記号と略号の表（何の略か・意味・単位）・初学者向けの解説（折りたたみ）
  - 根拠は法令・告示 → JIS → 国の基準 → 学会・協会の基準 → 便覧 の順に優先。公的な表は内蔵し、便覧・学会基準の表の値は利用者が入力する
- Excel 出力：計算式を Excel の関数として書き込んだ計算書（.xlsx）。入力セルを変えると Excel 上で再計算される
- 印刷：A4 の計算書として印刷・PDF 保存
- 検索（Ctrl / ⌘ + K）、分類での絞り込み、複数ツールのタブ、閲覧履歴、お気に入り、ダークモード（いずれもブラウザ内に保存）

## デザイン

- 配色：配管の識別表示（JIS Z 9102）の識別色で分類を示す「識別色」案
  - 空調＝空気（白）、給排水＝水（青）、電気＝電気（うすい黄赤）、消防・防災＝消火（赤）、共通＝灰
  - 分類ラベルは配管の識別表示にならった矢印形。色だけに頼らず分類名を必ず併記する
- 構成：グラファイトのサイドバー（分類とツールのツリー）、開いたツールのタブ、表形式の一覧、下端の状態バー
  - スマホではメニューボタンでサイドバーを引き出す
- 共通の基準（デジタル庁デザインシステムを参考）
  - 本文・操作部品は 16px 以上（14px は表の見出し・注記などの例外のみ）。スマホ幅（720px 以下）では全体を 14px 基準に縮小する（文字の大きさは rem で指定）
  - 文字と背景のコントラストは 4.5:1 以上、入力欄の枠線などは 3:1 以上（ライト・ダークとも）
  - フォーカスは黄色と黒の二重リング、判定はアイコンと文字（適合／不適合）で示す
- 書体：Noto Sans JP で統一（数値は桁のそろう等幅数字）。ツールID（XX-01）だけ Noto Sans Mono。Google Fonts から読み込む
- デザイントークンは `src/styles/global.css` の先頭にまとめている

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm test           # テスト（計算値の検証、Excel 式と画面の値の一致確認）
npm run typecheck  # 型チェック
npm run build      # 本番ビルド（dist/）
```

技術構成：Vite + React + TypeScript、react-router（HashRouter）、exceljs（Excel 出力時のみ遅延読み込み）。
テストでは HyperFormula（Excel 互換の計算エンジン）で、出力する Excel 式を実際に評価しています。

## ディレクトリ構成

```
src/
  core/        計算書の行データ、数式の置換、入力の検証、Excel 出力、保存処理
  tools/       計算ツール本体（1ツール1ファイル）と登録一覧 registry.ts
  components/  画面部品（サイドバー、タブ、一覧表、分類ラベル、入力欄、結果表示、検索ダイアログなど）
  pages/       ホーム、ツール画面、履歴、このサイトについて
  styles/      デザイン（CSS 変数でライト／ダークを切替）
```

## ツールの追加方法

1. `src/tools/` にファイルを追加し、`ToolDef` を定義する
   - `fields`：入力フォームの定義（数値・選択）
   - `build`：計算本体。`SheetBuilder` で行を積み上げる
     - `input(key, ...)`：入力値の行
     - `calc(key, ..., { value, expr, formula })`：計算行
       - `value`：JavaScript で計算した値（画面表示用）
       - `expr`：表示用の式。`{key}` が記号と数値に置き換わる
       - `formula`：Excel 用の式。`{key}` がセル番地に置き換わる
     - `judge(...)`：OK / NG の判定行
2. `src/tools/registry.ts` の `TOOLS` に登録する
3. `src/__tests__/tools.test.ts` に手計算値のテストを追加する
   （Excel 式と `value` の一致は全ツール共通のテストで自動的に確認される）

## 公開

`main` へのマージで GitHub Pages に公開するワークフロー（`.github/workflows/deploy.yml`）を用意しています。
初回のみ、リポジトリの Settings → Pages → Source を「GitHub Actions」に設定してください。
`dist/` は静的ファイルのみなので、Vercel・Netlify・Cloudflare Pages などにもそのまま置けます。
